# golmok 대비 기능 커버리지 — 서비스 기능 × 필요 데이터 × 가능 여부

> 목표(2026-08-06 사용자 방침): **모델이 데이터 주체인 채로**(ML 피처든 단순 CSV든)
> 서울시 상권분석서비스(golmok)의 **뜨는 상권 · 나는 사장 · 나도 곧 사장** UI/기능을
> 가능한 한 유사하게 구현한다.
>
> 실측 근거: [BENCHMARK-golmok.md](BENCHMARK-golmok.md) (7/22 탐색 + 8/5 리포트 52섹션 + 8/6 나는 사장).
> 상태는 기능이 배포될 때마다 이 표를 갱신할 것.

## 판정 기준

- ✅ **구현됨** — 배포에 있음
- 🔧 **가능** — 데이터는 모델 저장소에 있음. export/웹 작업만 하면 됨
- ⚠️ **부분** — 근사·대체로만 가능 (한계를 화면에 명시)
- ❌ **불가** — 데이터 자체가 없음 (golmok 내부 데이터, 공공 API 로도 못 받음)

## 2. 🔧 가능 — 작업만 하면 됨

| 서비스 기능 | 필요한 데이터 | 보유 확인 | 비고 |
|---|---|---|---|
| ~~가구수 블록~~ → **✅ 8/6 구현 (총가구만)** | `TOT_HSHLD_CO` | ✅ | ⚠️ **아파트/일반 분해는 불가로 판명** — `APT_HSHLD_CO` 가 전 분기·전 상권 0 (원본이 컬럼만 있고 값 미제공, `NON_APT`=`TOT` 복사). 분해를 내보내면 "아파트 0%" 거짓이 된다. golmok "가구세대(아파트vs일반)" 완전형은 ❌로 이동 |
| 유동인구 연령대 필터 랭킹 | 연령별 유동인구 6구간 | ✅ `population.csv` | rankings 에 연령 분해 추가 |
| 기준분기 선택 (과거 분기 랭킹) | 21분기 원본 | ✅ 원본 CSV | export 가 분기별 스냅샷을 실으면 됨 |
| ~~행정동 4단 비교~~ → **✅ 8/6 구현** (⑤ 밀도) | `행정동_코드` + export 동 중앙값 | ✅ | 동 안에 상권 1개뿐이면(자기 자신) export 가 null → UI 생략. 임대는 값이 gu_mean 이라 동 층 무의미 — 서울 대비만 유지 |
| 반경/다각형 영역 → 상권 필터 | 상권 좌표 | ✅ `meta/sangwons.json` | ⚠️ 영역 **재집계 금지** (웹이 수치를 만들게 됨) — 상권 목록 필터 + 개별 리포트 연결로 |
| 주소/장소 검색 (자동완성) | 카카오 지도 SDK 부속 | ✅ | 위치 입력 수단 — 데이터 주체 정책과 무관 |
| 인구밀도 지도 레이어 | 밀도 3종 | ✅ 서빙 | 상권 단위 원 색칠 (골목상권처럼 ha 격자는 불가) |

## 3. ⚠️ 부분 — 근사·대체

| 서비스 기능 | 필요한 데이터 | 한계와 대체 |
|---|---|---|
| 행정동 폴리곤 + 수치 라벨 지도 | 행정동 경계 GeoJSON | 모델에 없음 (도입하면 데이터 주체 정책 위반) → 상권 점 마커·라벨로 대체. '뜨는 동네'는 리스트+드릴다운으로 해소 |
| 상권영역 표시 | 상권 폴리곤 경계 | 좌표+면적만 보유 → **원 근사** (현행 유지) |

## 4. ❌ 불가 — 데이터 자체가 없음

golmok 이 내부적으로만 보유한 데이터라 공공 API 로도 받을 수 없다.
**"제공하지 않는 항목" 패턴**(리포트 ⑦ 방식)으로 이유와 함께 화면에 밝힌다.

| 서비스 기능 | 필요한 데이터 | 참고 |
|---|---|---|
| 보행권역/보행시간 분석영역 | 보행 네트워크 | 반경/다각형(🔧)으로 갈음 |
| 점포이력 지도 레이어 | 개별 점포 개폐업 이력 | 우리는 상권×업종 **집계**만 보유 |
| 유동인구 도로별/건물별 레이어 | 도로·건물 단위 유동인구 | 상권 단위만 보유 |
| 소득 7분위 | 소득 데이터 | `income.csv` 는 지출만 (기존 확정 한계) |
| 평균영업기간 | 점포 영업기간 | `store.csv` 에 없음 (개폐업 수/율만) |
| 가구의 아파트/일반 **분해** | `APT_HSHLD_CO` 실측값 | 컬럼은 있으나 전 구간 0 (8/6 실측) — 총가구만 제공, 아파트 세대는 아파트-상권 데이터셋으로 교차 표기 |
| 연차별 생존율 (1~5년차) | 연차별 생존 데이터 | 3년 환산(축소추정)이 우리 설계 결정 — 유지 |

## 우리가 golmok 보다 나은 것 (실측 확인 — 빼면 손해)

- 랭킹 행 클릭 → 분석 진입 (golmok 은 랭킹에 클릭 핸들러가 없다)
- 증가율 랭킹의 소표본 노이즈 처리 (`lowBase` — golmok 은 "5만원 +326%" 가 1위)
- 동네 → 상권 드릴다운 (golmok 에 없는 경로)
- 종합점수·등급 / AI 예측 / 치안 / 독립점포 분석 / AI 인스펙터 (golmok 에 없음)
- 표본 부족의 정직한 처리 (축소추정 + low_sample 경고 — golmok 은 그대로 노출)
