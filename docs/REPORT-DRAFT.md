## 1. 연구 배경 및 목적

예비창업자는 "이 자리에 이 업종으로 창업해도 될까"라는 질문에 답할 정량 근거가
부족하다. 서울시 상권분석서비스(golmok) 등 기존 공공 서비스는 매출·유동인구·점포 수
실측 통계를 **보여주는 데** 그치며, 미래에 대한 예측이나 종합 판단을 제공하지 않는다.

본 연구는 서울시 공공데이터만으로 **다음 분기 점포당 매출을 예측하는 기계학습 모델**을
구축하고, 그 예측을 실측 통계·규칙 판정과 결합해 창업 의사결정을 돕는 웹 서비스
"상권 인사이트"로 구현했다. 대상은 서울시 62개 생활밀접업종 × 1,570개 상권이다.

## 2. 데이터

서울 열린데이터광장 상권분석서비스 API 로 수집한 6종(분기 단위)을 사용했다.

| 데이터 | 내용 | 규모 |
|---|---|---|
| 추정매출 | 상권×업종별 분기 카드매출과 요일·시간대·성별·연령 구성 | 218,304행 (2023Q1~2025Q2) |
| 점포 | 업종별 점포 수(프랜차이즈 구분), 개·폐업 | 767,251행 |
| 길단위 유동인구 | 상권별 유동인구와 구성 | 상권×분기 |
| 상주·직장인구 | 배후 수요 (성별·연령·가구) | 각 34,000여 행 (2021Q1~2026Q1) |
| 영역 | 상권 좌표(EPSG:5181)·면적 | 1,570개 상권 |
| 외부 | 경찰청 5대범죄(2024)·CCTV(2025)·R-ONE 임대시세 | 자치구 단위 |

**데이터 정합성 검증을 전처리의 핵심 단계로 두었다.** 대표 사례 두 가지:
(1) 원천의 `점포_수`는 전체가 아니라 프랜차이즈 제외 수임을 767,251행 전수 검증으로
확인하고 학습 타깃 분모를 교정했다. (2) `당월_매출_금액`은 명칭과 달리 분기(3개월)
합계임을 공식 서비스와의 교차 대조로 실증하고 서비스 표기를 정정했다.

## 3. 모델 설계

- **타깃**: `다음 분기 매출 ÷ 다음 분기 전체 점포 수` (상권×업종 점포당, 분기)
- **모델**: RandomForest 회귀 (후보 6종 — 나이브 2·RF·XGBoost·LightGBM·CatBoost —
  중 검증 성적으로 선정), 학습 191,643행
- **검증**: 시간 경계 분할(마지막 분기 = test) + walk-forward 4-fold.
  미래 정보가 학습에 새지 않도록 모든 파생 피처를 t 시점 이전 값으로만 구성
- **베이스라인**: "다음 분기 = 지난 분기" 나이브 규칙. 분기 집계 데이터는
  자기상관이 강해 이 규칙이 매우 강력하다 — 이를 이기는 것을 채택 기준으로 삼았다

## 4. 모델 성능 — 실패의 진단과 개선 [장표 F2]

초기 모델(v1)은 **나이브 베이스라인에 1.5% 뒤졌다** (test MAE 1,378만원 vs 1,357만원).
이 실패를 은폐하지 않고 성적표에 기록한 뒤 원인을 실험으로 추적했다.

| 가설 | 실험 결과 |
|---|---|
| 학습 타깃 분모 오염 (프랜차이즈 제외 점포 수) | ✅ 확인 — 교정 시 ML 우위 2배 |
| 검증셋 1분기 과적합 (모델 선정 왜곡) | ✅ 확인 — 2분기로 확대해야 승리 |
| 수요 피처(상주·직장인구) 부재 | ❌ 기각 — 추가해도 ±0.03% |
| 외부 피처(치안·부동산) 결측 | ❌ 기각 — 0.5% 미만 |

두 원인을 함께 교정한 v2 는 **나이브 대비 MAE 2.7% 우위** (1,038만원 vs 1,067만원),
SMAPE 26.5%, R² 0.94 를 기록했다. 업종·상권유형별 오차를 분해해 성적표에 담았고,
이 값이 서비스의 "예측 신뢰도" 표기가 된다 (예: 커피-음료 ±21%, 직장형 상권 ±25.9%).

**개선 폭(2.7%)보다 중요한 것은 과정이다** — 예측이 규칙에 지는 것을 확인하고,
가설 4개를 실험으로 채택/기각하고, 데이터 결함을 교정해 역전시킨 전 과정이
저장소에 재현 가능하게 기록되어 있다.

## 5. 모델의 서비스 적용 — 예측이 화면을 관통한다 [장표 F1, F3]

예측값은 단일 숫자 표시에 그치지 않고 서비스의 판단 체계 전체의 원천이 된다.

1. **직접 표시** — 리포트 ③ "예상 매출 N만원/분기" (월평균 병기), 업종별 히트맵 색,
   업종 랭킹의 예상매출
2. **종합진단의 핵심 성분** — 예측값의 업종 내 백분위가 종합진단 최대 가점 성분
   (매출잠재력 30%)이 되며, 정책상 예측 없이는 종합진단 산출 자체가 차단된다
3. **파생 판단** — 종합진단 → 상권 내 업종 기회 순위 → 히트맵 종합점수 →
   강점/리스크 문장 1순위까지 예측 위에 서 있다

즉 사용자가 보는 "이 상권에서 유망한 업종 순위"와 "종합 판정"은 모두 ML 예측을
1차 입력으로 하는 파이프라인의 출력이다.

## 6. 신뢰성 설계 — 예측을 정직하게 파는 방법 [장표 F4]

AI 서비스의 신뢰는 정확도만으로 만들어지지 않는다. 본 서비스는 예측·통계의 한계를
화면이 스스로 밝히는 장치를 두었다.

- **예측 신뢰도 표기**: 학습에 쓰지 않은 분기로 채점한 업종·상권유형별 오차(±N%)를
  예측값 옆에 상시 표시
- **소표본 극단값 경고**: 점포 몇 개 평균이라 값이 튀는 상권(예: 업종 중앙값의 23배)은
  경고문을 자동 부착 — 판정·문구 모두 파이프라인이 생성
- **생존율 축소추정**: 소표본 상권의 관측 폐업률을 업종 평균으로 보정(Empirical Bayes,
  k=20) — 보정 없이는 표본 부족 상권의 76.8%가 "생존율 100%"로 표시된다
- **출처 계보 공개**: 화면의 모든 숫자를 예측/실측/통계 가공/규칙 판정으로 분류해
  실시간 콘솔(AI 인스펙터)로 공개 — "ML 이 어디에 쓰였는가"에 화면이 직접 답한다
- **해석 문장은 규칙 기반(결정적)**: 생성형 모델을 쓰지 않아 수치 왜곡·환각 위험이
  구조적으로 없다. 같은 입력은 항상 같은 문장을 낳아 심사·재현이 가능하다

## 7. 확장 실험 — 폐업 위험 예측의 타당성 [장표 F5]

현재 생존율은 실측 폐업률의 통계 환산이다. 이를 ML 예측으로 승격할 수 있는지
동일 방법론(walk-forward 4-fold)으로 타당성 실험을 수행했다.

| 지표 (4폴드 평균) | ML | 현행(축소추정) | 개선 |
|---|---|---|---|
| MAE | 3.98%p | 4.07%p | +2.1% (4/4 폴드) |
| 순위 상관 (Spearman) | **0.291** | 0.173 | **+68%** |
| 상위 10% 위험 조합 포착률 | **24.0%** | 16.1% | **+49%** |

절대 오차 개선은 근소하나, **위험 상권을 걸러내는 랭킹 능력에서 뚜렷한 우위**를
확인했다 — 서비스의 신호등이 "위험한 곳을 놓치지 않는 것"을 목적으로 하는 만큼
실질적 가치가 있는 방향이며, 정본 파이프라인 편입을 향후 과제로 제안한다.

## 8. 한계 및 향후 과제

- 매출 원천이 카드 결제 기반 추정치이므로 절대 금액이 아닌 상권 간 비교 지표로
  해석해야 한다 (서비스 전면에 면책 표기)
- 점포 수가 적은 상권×업종 조합의 값 변동성 (극단값 경고·축소추정으로 완화)
- test 성적이 단일 분기 기준 — 분기별 성적 흐름을 보는 **롤링 백테스트 전 구간 확장**이
  1순위 후속 과제 (walk-forward 4-fold 는 확보)
- 폐업 예측 모델의 정본 편입 검토 (§7)
