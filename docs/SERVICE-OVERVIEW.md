# 상권 인사이트 — 서비스 기능 · 데이터 총람

> 제출·팀 공유용 한 장 정리. 기준: 2026-08-07 배포본 (`bbcd962`).
> 깊이가 필요하면 — golmok 대비 커버리지는 [GOLMOK-PARITY.md](GOLMOK-PARITY.md),
> 서빙 테이블 컬럼 단위 매핑은 [DATA-CATALOG.md](DATA-CATALOG.md).

**한 줄 요약**: 서울시 공공데이터 실측 + 자체 학습 모델(RandomForest v2.0.0)의 예측으로
"이 자리에 이 업종, 들어가도 될까?"에 답하는 지도 데모.
**62개 생활밀접업종 × 1,570개 상권** (랭킹은 1,650개), 모든 수치에 출처 표기.

**설계 원칙** (전 기능 공통):
- **데이터 주체는 모델 저장소** — 값·집계·판정 전부 파이프라인(`export_web_static.py`)
  산출이고 웹은 정렬·필터·표시만 한다
- **목업 없음** — 전부 실데이터. 없는 항목은 숨기지 않고 "제공하지 않는 항목 + 이유"로 노출
- **AI 인스펙터** — 지도 우하단 콘솔이 요청/응답/숫자별 출처 계보를 실시간 공개

## 2. 기능 — 대메뉴 3개 + 지도

### 🗺 지도 (공통)

| 기능 | 데이터 | 비고 |
|---|---|---|
| 주소·장소 검색 (자동완성) | 카카오 Places | 좌표 → 최근접 상권 자동 매핑 |
| 지도 클릭 → 상권 매핑 | 상권 좌표 | 반경 500m 밖이면 사유 + 최근접 제안 |
| 선택 상권 **영역 원 근사** | `영역_면적` | 등면적 원(√(A/π)) + "N ha 근사" 라벨 + 클릭 지점 연결선 (폴리곤 원천 없음을 명시) |
| 업종 히트맵 (업종부터 모드) | 매출 백분위 / 생존율 / 종합점수(+치안 5% 토글) | 색 기준 3종 전환 |
| AI 인스펙터 콘솔 | 전 API 트래픽 | MAP→GEO→REQ→MODEL→RES 체인 + 숫자별 계보(ML/통계/실측/규칙) |

### 📊 상권 분석 (메인)

**진입 2갈래**: 자리부터(클릭/검색 → 주변 상권 반경 300m/500m/1km 목록 → 업종 기회 랭킹
→ 업종 선택) / 업종부터(업종 선택 → 히트맵 → 상권 클릭). 어느 쪽이든 같은 리포트로 수렴.

**업종 기회 랭킹** — 그 상권의 유망 업종 순위 (창업기회점수 ⇄ 분기 예상매출 정렬).

**분석 리포트 8섹션** (섹션 점프 내비 + 스크롤 하이라이트, 라이트/다크 토글 — 기본 라이트):

| # | 섹션 | 제공 정보 | 성격 | 데이터 |
|---|---|---|---|---|
| ① | 종합 의견 | 신호등(양호/주의/위험) + 지표 불릿 + 시장단계(5종) + **모델 종합진단 분해**(점수/등급/성분 9바/가중치) | 규칙+통계 | 종합진단, market_stage |
| ② | 생존 전망 | 3년 생존율 게이지 | **실측 환산** — `(1−분기폐업률)^12`, 소표본 축소추정(k=20) | store 폐업률 10분기 |
| ③ | 매출 분석 | **점포당 분기 예측**(+월평균 ÷3 병기) · 업종 중앙값 대비 배수 · **극단값 경고**(소표본 10배↑) · 예측 신뢰도(업종/유형 SMAPE) · 실측 분해(요일/시간/성별/연령) · 5분기 추이 · 증감 배지 | ML 예측 + 실측 | pkl 예측, sales |
| ④ | 업종·경쟁 | 점포·프랜차이즈·개폐업 · **독립점포 관점 매출**(k 추정/시나리오) · 상권/자치구/서울 3단 비교 | 실측 + 통계 추정 | store, 독립점포 k |
| ⑤ | 인구 분석 | 유동인구 + 분해 + 8분기 추이 · **밀도 3종 4단 비교**(상권/동/구/서울 중앙값) | 실측 | population, 밀도 |
| ⑥ | 치안 참고 | 자치구 5대범죄(건수·죄종별·순위·10만명당·서울 평균 대비) + 종합점수 치안 토글 | 실측 | 경찰청 2024·CCTV 2025 |
| ⑦ | 배후지 | 상주/직장인구(성별·연령) · **총 가구** · 아파트 · 집객시설 · 소비지출 9종 · 임대 시세(서울 중앙값 대비) · **제공하지 않는 항목**(소득분위 등 + 이유) | 실측 | 인구 CSV, 이월 3종, R-ONE |
| ⑧ | 유의사항 | 생존율 성질·집계 수준·소표본·기준 분기 혼재 안내 | — | scaleNote 등 서버 주입 |

+ ⑨ 데이터 출처 (실제 사용한 데이터셋만 나열) · **비교에 담기** (최대 3개 → 비교함).

## 3. 정직성 장치 (전 화면)

| 장치 | 내용 |
|---|---|
| 분기 단위 명시 | 매출은 전부 "/분기" + 월평균(÷3) 병기 — 원천 `당월_매출_금액`이 분기 합계임을 golmok 대조로 실증 (8/7) |
| 극단값 경고 | 업종 중앙값 10배↑ & 소표본이면 ⚠ "점포 N개 평균 — 대형 사업장 영향 가능" (export 판정) |
| 축소추정 | 생존율 소표본을 업종 사전률로 보정 — 안 하면 "생존율 100%" 가 화면에 뜬다 |
| 집계 기준 노출 | "62업종 합계" · "자치구 평균 조인(gu_mean)" · "영역 근사" 등 전부 화면 표기 |
| 제공하지 않는 항목 | 소득분위·보행권역·점포이력·연차별 생존율 등 — 데이터 부재 사유와 함께 노출 ([PARITY §4](GOLMOK-PARITY.md)) |
| sourceMode | 모든 응답에 live/file/mock — 목업이면 배지 (현재 목업 경로 없음) |
