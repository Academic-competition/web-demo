# 상권 인사이트 — 데이터에서 화면까지

> 제출·팀 공유용 한 장 정리. 기준: 2026-08-07 배포본.
> 개발자용 상세(컬럼·파일 단위)는 [DATA-CATALOG.md](DATA-CATALOG.md),
> 서울시 공식 서비스와의 비교는 [GOLMOK-PARITY.md](GOLMOK-PARITY.md).

**서비스 한 줄** — "이 자리에 이 업종, 들어가도 될까?"에 서울시 공공데이터 실측과
자체 학습 모델의 예측으로 답하는 지도 데모. **서울시 62개 생활밀접업종 × 1,570개 상권.**

## 0. 전체 흐름

```
서울 열린데이터광장 (공공 실측)          모델 저장소 (Commercial-AI-)              웹 데모
─────────────────────────       ─────────────────────────────       ──────────────────
매출·유동인구·점포·인구 등    →    수집 → 학습(매출 예측 모델)          →    지도 + 3개 메뉴로 표시
자치구 범죄·CCTV·임대 시세          + 집계·점수·판정 파이프라인               (정렬·필터만, 숫자를
                                                                          새로 만들지 않음)
```

핵심 원칙: **모든 숫자는 모델 쪽 파이프라인이 만든다.** 웹은 받은 값을 보여줄 뿐이고,
지도 우하단 **AI 인스펙터**가 숫자마다 "예측인지 / 실측인지 / 통계 가공인지 / 규칙
판정인지"를 실시간으로 공개한다.

## 1. 모델에서 무엇을 얻고, 화면에서 어떻게 보이나

### A. 모델이 **예측**한 것 (ML — 모델은 하나지만, 화면 전반을 관통한다)

| 얻은 데이터 | 무엇인가 | 웹에서 이렇게 보인다 |
|---|---|---|
| **점포당 예상 매출** | 다음 분기에 이 상권×업종의 점포 1곳이 올릴 평균 매출. 과거 매출·점포·유동인구 등 19만 행으로 학습한 RandomForest 의 예측 (단순 규칙 대비 오차 2.7% 우위) | 리포트 **③ 매출 분석**의 큰 숫자("2,867만 /분기" + 월평균 병기) · 업종별 **히트맵 색** · 업종 기회 랭킹의 "분기 예상매출" |
| 예측이 얼마나 틀리나 (채점표) | 학습에 안 쓴 분기로 시험 본 결과 — 업종별·상권유형별 평균 오차(%) | ③ 예측 신뢰도: "이 업종 ±21% · 이 상권 유형에서는 ±26.7%" |

**예측의 파급 경로** — 이 예측값의 업종 내 백분위가 종합진단의 **최대 가점 성분
(매출잠재력 30%)** 이 되고, 종합진단은 예측 없이는 산출 자체가 막혀 있다(정책).
따라서 ① 진단 카드 · 업종 **기회 순위** · 히트맵 **종합점수** 색 · 강점 문장 1순위까지
전부 ML 예측 위에 서 있다. "ML 이 쓰인 곳"은 숫자 하나가 아니라 이 체인 전체다.

### B. 실측을 **그대로** 보여주는 것 (카드사·통신사·행정 데이터 기반 공공 집계)

| 얻은 데이터 | 무엇인가 | 웹에서 이렇게 보인다 |
|---|---|---|
| **매출 실적** | 상권×업종별 분기 카드매출 추정 — 총액과 요일·시간대·성별·연령대별 구성, 최근 5분기 흐름 | ③ 요일/시간대/성별/연령 차트 · 5분기 추이 · 전분기/전년 증감 배지 |
| **유동인구** | 상권을 지나간 사람 수(분기 연인원)와 그 구성 | ⑤ 인구 분석 전체 · 상권 TOP10 랭킹(연령대 필터 포함) |
| **점포 현황** | 업종별 점포 수(프랜차이즈 구분), 개업·폐업 수와 비율 | ④ 경쟁 분석 · 상권 TOP10 "점포 수" 랭킹 |
| **상주·직장인구** | 그 상권 배후에 사는 사람·일하는 사람 (성별·연령 포함) + **총 가구 수** | ⑦ 배후지 타일 · 랭킹 · 상권 유형(주거형/직장형 등) 분류 재료 |
| **치안** | 자치구별 5대 범죄 발생·검거(2024)와 CCTV(2025) | ⑥ 치안 카드 — 건수·죄종별·자치구 순위·10만 명당 |
| **임대 시세** | 자치구 평균 m²당 임대료·공실률·가격지수 (한국부동산원) | ⑦ 임대 타일 — "m²당 50,467원, 서울 중앙값보다 +7,067원" |
| 아파트·집객시설·소비지출 | 배후지의 아파트 단지/세대/시세, 사람을 모으는 시설(역·학교·병원…), 카테고리별 소비 지출 | ⑦ 배후지 나머지 타일 (소비지출은 2023Q4 이후 원본 미공개 — 기준 칩으로 명시) |

### C. 실측을 **가공한 통계** (산식을 화면·문서에 공개)

| 만든 지표 | 어떻게 만들었나 | 웹에서 이렇게 보인다 |
|---|---|---|
| **3년 생존율** | 예측이 아니라 실측 폐업률의 환산 — (1−분기폐업률)¹². 점포가 몇 개 없는 상권은 업종 평균 쪽으로 보정(축소추정) — 안 하면 "생존율 100%"가 떠버린다 | **② 생존 전망** 게이지 + 신호등(양호/주의/위험) 판정의 근거 |
| **인구 밀도** | 인구 ÷ 상권 면적 (명/km²) + 비교 기준으로 서울·자치구·행정동 중앙값 동봉 | ⑤ 밀도 타일 — "서울 중앙값의 12.6배" 4단 비교 · 랭킹 밀도 3종 |
| **종합진단 점수** | 매출잠재력 30%·성장 15%·수요 15%·경쟁 10%·치안 5% 가점 − 폐업위험 10%·임대부담 8% 등 감점 (가중치 파일 공개) | **① 진단 카드** (점수/100·등급·성분 9개 바) · 업종 **기회 순위**의 원천 |
| **독립점포 관점 매출** | "프랜차이즈 포함 평균"에서 독립 점포만의 기대치를 통계 추정 (업종별 배수 k — 품질 검증 통과 17/63 업종만) | ④ 독립점포 카드 — 통과 업종은 추정값, 미통과는 시나리오만 |
| **랭킹 재료** | 상권·행정동별 지표 14종의 값 + 전분기 증감 + 소표본 여부 판정 | **상권 TOP10** 메뉴 전체 (상권/동네) |
| 자치구 안전점수 | 범죄율(50%)·검거(25%)·CCTV 밀도(25%) 백분위 가중 | ⑥ + 히트맵 "치안 반영" 토글 |

### D. **규칙**으로 판정·서술하는 것 (조건부 템플릿, 결정적)

| 만든 것 | 규칙 | 웹에서 이렇게 보인다 |
|---|---|---|
| 신호등 판정 | 생존율 ≥60% 양호 / ≥45% 주의 / 미만 위험 | 리포트 헤더·히트맵 생존율 색 |
| 시장 단계 | 개업률·폐업률·점포 증감의 조합 → 성장기/안정기/경쟁심화기/재편기/쇠퇴기 | ① 경쟁 불릿 |
| 해석 문장 | "값 → 판단 → 조언" 조건부 템플릿 (예: 매출 백분위 75 이상 → "매출 체력은 상위권 — 남은 변수는 비용·경쟁 검증") — 필요한 값이 없으면 문장 생략, 지어내지 않음 | ① 종합 의견 불릿·요약문 |

### E. **생성형 AI** 로 요약하는 것 (베타 · **로컬 전용** — 유일한 LLM 사용처)

> ⚠️ 배포본(Vercel)에는 노출하지 않는 로컬 테스트 기능이다 —
> `NEXT_PUBLIC_BUZZ_ENABLED=true` 인 환경에서만 카드가 렌더된다 (2026-08-07 결정).

| 만든 것 | 어떻게 만들었나 | 웹에서 이렇게 보인다 |
|---|---|---|
| **SNS 언급 분석** | 버튼을 누르면 네이버 블로그·카페에서 그 상권×업종 글을 실시간 수집 → Claude 가 광고·협찬 글을 걸러내며 메뉴·키워드·분위기·시사점을 구조화 요약. **비정형 텍스트 × 생성형 AI** — A(정형 예측)와 짝을 이루는 하이브리드 축 | 리포트 ⑦과 ⑧ 사이 점선 카드 "SNS 언급 분석 — 생성형 AI · 베타" |

**D 와의 경계를 명확히 한다** — 리포트 본문의 해석 문장은 여전히 규칙 기반(결정적,
같은 입력 → 같은 문장)이고, 이 베타 카드만 생성형이다. 그래서 ① 자동 실행하지 않고
버튼 옵트인, ② "실행마다 달라질 수 있음" 라벨 상시 표기, ③ 수집 원문(제목·링크·날짜)
전체 공개, ④ 표본 한계(건수·광고 의심 비율)를 모델이 스스로 진단해 요약보다 먼저 표시,
⑤ 계보 분류에 "생성형 AI" 층을 추가해 인스펙터에 기록. 렌더 게이트와 별개로 서버
환경변수(`NAVER_CLIENT_ID/SECRET`, `ANTHROPIC_API_KEY`)가 없으면 사유를 밝히고 비활성.

## 2. 화면 구성 (대메뉴 3개 + 지도)

| 화면 | 역할 | 흐름 |
|---|---|---|
| 🗺 **지도** (공통) | 위치 선택·범위 안내 | 주소 검색/클릭 → 최근접 상권 매핑 · 선택 상권 **영역 원**(면적 근사) · **서울 밖은 어둡게** 마스킹 + "서비스 범위 서울시" 배지 |
| 📊 **상권 분석** | 메인 — 리포트 | 자리부터(지도→주변 상권 반경 목록→업종 기회 랭킹) 또는 업종부터(히트맵) → **8섹션 리포트** (위 A~D 가 전부 여기 모임) · "비교에 담기" |
| 📈 **상권 TOP10** | 탐색 시작점 | [상권\|행정동] × 지표 14종 × [수준\|증가율] TOP10 · 동네 클릭 → 소속 상권 드릴다운 → 분석 진입 (구명 '뜨는 상권' — golmok 메뉴명과 겹쳐 8/7 개명) |
| ⚖️ **비교함** | 후보 비교 | 담은 (상권×업종) 최대 3개를 17개 항목으로 나란히 — 리포트 값 그대로, 재계산 없음 |

리포트는 라이트(기본)/다크 토글, 섹션 점프 내비(스크롤 하이라이트) 제공.

## 3. 정직하게 밝히는 것들

**숫자 옆에 항상 붙는 것** — 기준 분기 칩(데이터마다 시점이 다르다: 매출·점포 2025Q2 ·
인구 2026Q1 · 소비지출 2023Q4) · 집계 범위("생활밀접업종 62종 합계", "자치구 평균",
"영역 근사") · 출처 라벨(예측/실측/통계/규칙/생성형).

**스스로 경고하는 것** — 점포 몇 개 평균이라 값이 튀는 상권은 ⚠ "동일 업종 중앙값의
23배 · 점포 8개 평균 — 대형 사업장 영향 가능" 박스가 자동으로 붙는다. 매출은 전부
**분기 기준**임을 값 옆에 명시(월평균은 ÷3 환산 병기).

**제공하지 않는 것** (원천 데이터가 없음 — 화면에도 사유와 함께 표시):
소득 분위 · 보행권역 분석 · 개별 점포 이력 · 도로/건물 단위 유동인구 · 평균 영업기간 ·
연차별(1~5년) 생존율 · 행정동 경계 지도. 상세는 [GOLMOK-PARITY.md](GOLMOK-PARITY.md) §4.
